# planes-webkit-catalog

Public GitHub Pages catalog for the private `planes-webkit` UI library.

The synthetic catalog previews a **2.0.0 development candidate**. The candidate adds standard CSS for ordinary HTML, typography-based quotations and square document tables/code, Drawer navigation with flat search results, and notification control through ToastViewport. This preview does not publish or release the private library; the released packages remain at 1.4.0.

Examples contain no private OCR text/images, package tarballs or source maps. The existing static Pages workflow is preserved.
