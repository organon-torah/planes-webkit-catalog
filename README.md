# planes-webkit-catalog

Public GitHub Pages catalog for the private `planes-webkit` UI library.

The synthetic 1.3.1 catalog demonstrates shared document headings, blue marker
links, tables, compact plaintext code with an icon CopyButton (check after copy,
then automatic restoration), read-only tasks,
allowlisted icons and NumberStepper using the common Button. It includes no
private OCR text/images, package tarballs or source maps. The existing owner-managed
static Pages workflow is preserved.

https://organon-torah.github.io/planes-webkit-catalog/
